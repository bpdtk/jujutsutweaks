## 二、改完代码怎么重新打包

**必须用 JDK 17。** 你的默认 `JAVA_HOME` 是 21，直接用会出问题。

```bash
cd "D:/md/新建文件夹/forge-1.20.1-47.4.10-mdk"

export JAVA_HOME="D:/md/dev/.gradle/jdks/eclipse_adoptium-17-amd64-windows/jdk-17.0.20.1+1"
./gradlew build
```

产物：`build/libs/jujutsutweaks-<版本号>.jar`

> 想省事的话，可以把这个 JDK 路径设成系统环境变量，以后就不用每次 export 了。

## 三、发新版本（1.0.0 → 1.0.1）

**第 1 步：改版本号**

打开 `gradle.properties`，改这一行：

```properties
mod_version=1.0.1
```

**第 2 步：重新打包**

```bash
export JAVA_HOME="D:/md/dev/.gradle/jdks/eclipse_adoptium-17-amd64-windows/jdk-17.0.20.1+1"
./gradlew build
```

**第 3 步：提交推送**

```bash
git add -A
git commit -m "v1.0.1: 说明你改了什么"
git push
```

**第 4 步：发 Release**

1. 打开 https://github.com/bpdtk/jujutsutweaks/releases
2. 点 **`Draft a new release`**
3. **Choose a tag** 输入 `v1.0.1`（要和版本号一致，带个 v）
4. **Release title** 填 `JujutsuTweaks v1.0.1`
5. 描述里写改了什么
6. 把 `build\libs\jujutsutweaks-1.0.1.jar` **拖进附件区**
7. 点 **`Publish release`**

> 分享给别人的链接永远是 `https://github.com/bpdtk/jujutsutweaks/releases/latest`，
> 它会自动指向最新版，不用每次重新发链接。

## 五、出问题了怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 构建报 `Unsupported class file major version 65` | 用了 JDK 21 | 按上面第二条，显式指定 JDK 17 |
| 构建报 `Could not find method mixin()` | `build.gradle` 里 mixin 插件那行被删了 | 恢复 `id 'org.spongepowered.mixin' version '0.7.38'` |
| 游戏里没效果 | 没生效 | 游戏内执行 `/jujutsutweaks status`，看「上一 tick 跳过实体」是不是 0 |
| 一进游戏就崩，报 `InjectionError` | 注入点没找到 | 主体版本不对，或 Minecraft 不是 1.20.1 |
| 模组列表里备注是乱码 | 中文写进了 `gradle.properties` | 备注只能写在 `mods.toml` 里，`gradle.properties` 只能有英文 |

### 验证补丁真的在干活

游戏内（需要 OP）：

```
/jujutsutweaks status
```

输出 `冻结: 开 | 上一 tick 跳过实体: 137 | ...`，那个数字就是当前维度里存着的咒灵数量。
一直是 0 说明要么没存咒灵，要么配置被关了。

## 六、改代码时最容易踩的三个坑

**1. 别把主体模组的类写进 import**

这个补丁的核心设计就是「一个主体类都不碰」。一旦 import 了 `net.mcreator.jujutsucraft.*`，
主体下次用 MCreator 重新打包就会崩。只靠维度 ID 字符串识别就够了。

**2. 中文别放 `gradle.properties`**

那个文件按 ISO-8859-1 读，中文会被写坏。备注一律写在 `src/main/resources/META-INF/mods.toml`。

**3. 配置事件要过滤 modId**

`ModConfigEvent` 是给所有模组广播的。直接 `get()` 自己的配置，如果别的模组先加载就会抛
`IllegalStateException`。`OptimizerConfig` 里已经有 `isOurs()` 判断，别删。

## 七、想加新功能时

先想清楚：**能不能只改原版行为，不碰主体类？**

- 能 → 继续用 Mixin 挂原版（`ServerLevel`、`Entity`、`Level` 等）
- 不能 → 那就得接受「主体一更新就可能失效」的代价，慎重

加完记得：
1. 用 JDK 17 打包
2. 开发服跑一次 `./gradlew runServer`，看日志有没有 `Mixing ... into ...`
3. 游戏内 `/jujutsutweaks status` 确认计数正常

## 八、目录约定

```
forge-1.20.1-47.4.10-mdk/
├── src/          源码（com.jujutsutweaks）
├── docs/         文档（01 跨版本diff报告 / 02 实现方案 / 03 本手册）
├── tools/        反编译工具（vineflower / cfr），jar 不入库
├── temp/         临时文件，可随时整个删掉
├── 主体版本/      六个主体 jar，只读，不上传
└── build/        构建产物
```

**根目录不放临时文件。** 新东西要么进 `src`，要么进 `docs`，要么进 `temp`。
